# Marketing Campaign Analysis

## Project Overview

This project analyzes customer demographics, product spending, purchase-channel behaviour, and marketing campaign responses for a retail company containing 56,000 customer records.

The objective is to identify valuable customer segments, evaluate campaign performance, understand product and channel preferences, and support data-driven marketing decisions.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- MySQL
- MySQL Workbench
- Power BI
- Jupyter Notebook

## Project Components

- Data cleaning and validation
- Feature engineering
- Exploratory data analysis
- Rule-based customer segmentation
- MySQL database and analytical queries
- Power BI data model and interactive dashboard
- Business insights and recommendations
